# Let's DIY — Ver.2 検証結果

- 実施日: 2026-09-23
- 環境: Windows / Node.js 24.15.0 / Intel Core i5-14500
- コマンド: `npm run benchmark:v2`

## 運動学と干渉走査

部材 50 枚、revolute joint 10 本の合成プロジェクトで計測した。

| 項目 | 結果 | 基準 |
|---|---:|---:|
| `solvePoses` 中央値（1000 回） | 0.024 ms | 1 ms 未満 |
| `solvePoses` p95（1000 回） | 0.044 ms | 1 ms 未満 |
| `scanJointMotion` 36 ステップ | 31.1 ms | 1000 ms 未満 |

## 品質ゲート

| 項目 | 結果 |
|---|---|
| 型チェック | エラー 0 |
| Lint | エラー 0 |
| テスト | 449 件パス（48 ファイル） |
| core 行カバレッジ | 94.43% |
| 本番ビルド | 成功 |
| 初期 JavaScript gzip | 428.52 KB（基準 600 KB 以内） |
| schema 互換 | v1 / v2 / v3 検体の読込テスト通過 |
| `GeometryCache` | Ver.2 実装では変更なし |

`hashPartShape` は joint・金物を含めず、M12 の形状入力である `tiltAbout` / `tiltDeg`
だけを追加した。可動値の変更では形状ハッシュが変わらないため、CSG は再実行されない。

## 実画面確認

- 生成・配置・加工・金物・可動の 5 モードを表示
- スライド丁番の取り付けで joint とカップ穴を同時生成
- joint の角度スライダーと開閉ボタンを表示
- 金物由来の加工を直接編集不可として表示
- 木取り図、加工図、STL の出力メニューを表示

ブラウザの長時間 60fps 計測は端末・GPU・表示解像度に依存するため、開発用 `?perf=1`
プローブで継続確認する。運動学は描画フレームではなく project 更新時だけ再計算する。
